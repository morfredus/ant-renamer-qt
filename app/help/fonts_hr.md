# Font used for special characters

In the [options window](options_hr.md#display), the option "Force the following font..." replaces the font of the whole program (menus, lists, fields, log) by the font and the size that you choose. Unchecked, the program uses the font of your system.

You only need it if some characters are not displayed correctly (for example you see squares instead of the characters of a file name written in an Asian language, or symbols). Since Ant Renamer works with Unicode, any file name can be processed; this is only about how it is displayed.

A font that has all the characters you need makes the difference. The program recommends one of these, if one is installed on your system:

- Noto Sans, which can be obtained from [Google Fonts](https://fonts.google.com/noto),
- DejaVu Sans, which can be obtained from [DejaVu fonts](https://github.com/dejavu-fonts/dejavu-fonts),
- Arial Unicode MS, which came with older versions of Microsoft Office but was not included in default install (it is called "Universal font" in the installation options).

If you only use basic latin characters, you can select any font. The "Arial" font included in Windows should work for all European (West & Central) languages, Cyrillic, Greek, Hebrew and Arabic.

For some Asian languages, here is a list of fonts that can be used if they are installed on your system:

| Japanese: | MS PGothic, MS PMincho, MS Gothic, MS Mincho |
|---|---|
| Traditional Chinese: | MingLiU |
| Simplified Chinese: | SimSun, NSimSun |
| Korean: | GulimChe |
| Thai: | Tahoma |

On Linux, fonts such as "Noto Sans CJK" cover these languages.

The change of font is applied when you close the options window with "OK".
