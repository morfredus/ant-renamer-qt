## Ant Renamer Qt 3.1.1

Ant Renamer Qt is a C++/Qt 6 port of [Ant Renamer](https://www.antp.be/software/renamer/) by Antoine Potten: batch file renaming (replace, insert, move, delete, enumerate, change case, regular expressions, EXIF/IPTC/XMP/ID3 tags...) on Windows and Linux.

This is a small update of 3.1.0, the stable version. It is the code of 3.1.1-beta.1 with two more changes. What changes since 3.1.0:

- **Date and time and EXIF actions number the files given the same name** (`_01`, `_02`... in the order of the shooting): a burst shot in the same second no longer ends with refused files. New option *Number files given the same name* (Processing, on by default). The old *Add suffix* box of Date and time is removed.
- **One window at a time**: a second launch shows an information box and quits (two windows overwrote each other's undo history and settings). A file dropped on the program or its shortcut, or opened with "Open with", is added to the window that is already open. With `-g` or `-x` the message goes to the error output and the exit code is 3.
- **Adding a folder with no file** says "No file found in ..." in a message box, the status bar and the log.
- **Windows**: the program and the installer carry version information (product name and version in the file Properties).
- **Linux AppImage**: update information embedded, so AppImageUpdate can update it.
- Screenshots of the help remade with the 3.1 interface.

### Tested

All the changes of this version were tried by hand on Windows 11, on Linux Mint and on a Raspberry Pi 4 (Debian 13, arm64): the numbering of files given the same name, the second launch (message, then the window closes) and the files given to it, the message for an added folder that holds no file, and, on Windows, the version information in the file Properties. The Windows installer was tried as an upgrade over 3.1.0, as a fresh installation and as an uninstallation, and the AppImage and the `.deb` packages were tried too. Built from the source with no compiler warning (`-Werror`), unit and panel tests passing, clang-tidy without any finding (Windows 11, Ubuntu 24.04 under WSL2, Raspberry Pi 4). Your feedback is welcome.

## Ant Renamer Qt 3.1.1

Ant Renamer Qt est un portage C++/Qt 6 d'[Ant Renamer](https://www.antp.be/software/renamer/) d'Antoine Potten : renommage de fichiers par lots (remplacer, insérer, déplacer, supprimer, énumérer, changer la casse, expressions régulières, tags EXIF/IPTC/XMP/ID3...) sous Windows et Linux.

C'est une petite mise à jour de la 3.1.0, la version stable. C'est le code de la 3.1.1-beta.1 avec deux changements de plus. Ce qui change depuis la 3.1.0 :

- **Les actions Date et heure et EXIF numérotent les fichiers qui reçoivent le même nom** (`_01`, `_02`... dans l'ordre de prise de vue) : une rafale prise dans la même seconde ne finit plus avec des fichiers refusés. Nouvelle option *Numéroter les fichiers qui reçoivent le même nom* (Traitement, cochée par défaut). L'ancienne case *Ajouter un suffixe* de Date et heure disparaît.
- **Une seule fenêtre à la fois** : un deuxième lancement affiche une boîte d'information et quitte (deux fenêtres écrasaient mutuellement l'historique d'annulation et les réglages). Un fichier déposé sur le programme ou son raccourci, ou ouvert avec « Ouvrir avec », est ajouté à la fenêtre déjà ouverte. Avec `-g` ou `-x`, le message part sur la sortie d'erreur et le code de sortie est 3.
- **Ajouter un dossier sans fichier** affiche « Aucun fichier trouvé dans ... » dans une boîte de message, la barre d'état et le journal.
- **Windows** : le programme et l'installeur portent des informations de version (nom du produit et version dans les propriétés du fichier).
- **AppImage Linux** : informations de mise à jour intégrées, AppImageUpdate peut donc le mettre à jour.
- Captures d'écran de l'aide refaites avec l'interface de la 3.1.

### Testé

Tous les changements de cette version ont été essayés à la main sous Windows 11, sous Linux Mint et sur un Raspberry Pi 4 (Debian 13, arm64) : la numérotation des fichiers qui reçoivent le même nom, le deuxième lancement (message, puis la fenêtre se ferme) et les fichiers qu'on lui donne, le message pour un dossier ajouté qui ne contient aucun fichier, et, sous Windows, les informations de version dans les propriétés du fichier. L'installeur Windows a été essayé en mise à jour par-dessus la 3.1.0, en installation depuis zéro et en désinstallation, et l'AppImage et les paquets `.deb` ont aussi été essayés. Compilée depuis les sources sans aucun avertissement (`-Werror`), tests unitaires et du panneau réussis, clang-tidy sans aucun avertissement (Windows 11, Ubuntu 24.04 sous WSL2, Raspberry Pi 4). Vos retours sont les bienvenus.
