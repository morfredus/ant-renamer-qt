## Ant Renamer Qt 3.1.0-beta.1

Ant Renamer Qt is a C++/Qt 6 port of [Ant Renamer](https://www.antp.be/software/renamer/) by Antoine Potten: batch file renaming (replace, insert, move, delete, enumerate, change case, regular expressions, EXIF/IPTC/XMP/ID3 tags...) on Windows and Linux.

This is the first beta of 3.1, the version that follows the stable 3.0.0. It is a beta: it is published to be tried, and it is not offered as an update to someone who runs a final version, unless they tick "Also tell me about beta and release candidates" in the options.

### What is new since 3.0.0

- **Language and interface applied at once**: changing the language, or switching between the classic and the modern interface (or its pages layout), no longer needs a restart. The window is rebuilt when you click OK in the options; your files, batch and log stay.
- **Export of the preview**: *Export preview...* in the context menu of the files list writes the current and new names to a CSV file (semicolon, readable by Excel with its accents) or the new names only to a text file.
- **Add folders**: a field to type the path of a folder.
- **Command line**: a folder given with a trailing slash or backslash (`-afr d:\Data\`) is now added like one without it; before, it added nothing.
- **New-version check**: a box "Also tell me about beta and release candidates" in Options > Display (off by default). The Windows installer offers the same choice, with the start-up check, among its tasks.
- **Options**: the "Portable mode" box moves from the Language tab to the Display tab, in a "Settings storage" section. Switching the mode now reports an error when the old settings file cannot be removed (before, the mode did not change and nothing said so).
- **New program icon** (window, executable, installer, Linux packages, About box), and the About window shows the web site of the port next to the one of the original program.
- **Linux files signed with GPG** (a `.asc` next to each file and to `SHA256SUMS-linux.txt`; the public key and the verification commands are in the README). Windows files are not signed.
- **Linux .deb**: the menu icon is installed the way the icon theme expects it (SVG and PNG from 16 to 256 px).
- **Flatpak**: the packaging files for Flathub are in the repository (the package itself is not published yet).
- **Help and documentation**: screenshots of the program in English and French, pictures of the Options window made again.

Under the hood, the code was reviewed: the build is free of compiler warnings, the rows of the file and batch lists no longer hold raw pointers, the main window code is split into several files, the C++ files share one formatting (`.clang-format`), and a leak in the Options window (Cancel) is fixed. No change in how the program renames.

### Tested

Built and tried on Windows 11 (MinGW) and on Linux, with the engine tests passing. The change of language, of interface and of theme without restarting was checked on Windows and on Linux, with the `.deb` package installed and with the AppImage (classic to modern, English to French and back, with files in the list: they stay). The portable mode was tried by hand (the `antrenamer-qt.ini` file appears in the program folder when the box is ticked and disappears when it is cleared). The Windows installer, the ARM64 package and the Raspberry Pi have not been tried yet with this beta: your feedback is welcome.

## Ant Renamer Qt 3.1.0-beta.1

Ant Renamer Qt est un portage C++/Qt 6 d'[Ant Renamer](https://www.antp.be/software/renamer/) d'Antoine Potten : renommage de fichiers par lots (remplacer, insérer, déplacer, supprimer, énumérer, changer la casse, expressions régulières, tags EXIF/IPTC/XMP/ID3...) sous Windows et Linux.

C'est la première bêta de la 3.1, la version qui suit la 3.0.0 stable. C'est une bêta : elle est publiée pour être essayée, et elle n'est pas proposée comme mise à jour à quelqu'un qui utilise une version finale, sauf s'il coche « Me signaler aussi les versions bêta et release candidates » dans les options.

### Nouveautés depuis la 3.0.0

- **Langue et interface appliquées tout de suite** : changer la langue, ou passer de l'interface classique à la moderne (ou changer la disposition des pages), ne demande plus de redémarrer. La fenêtre est reconstruite quand vous cliquez sur OK dans les options ; vos fichiers, votre job et votre journal restent.
- **Export de l'aperçu** : *Exporter l'aperçu...* dans le menu contextuel de la liste des fichiers écrit les noms actuels et nouveaux dans un fichier CSV (point-virgule, lisible par Excel avec ses accents) ou les seuls nouveaux noms dans un fichier texte.
- **Ajouter des dossiers** : un champ pour saisir le chemin d'un dossier.
- **Ligne de commande** : un dossier donné avec une barre oblique ou inverse finale (`-afr d:\Data\`) est maintenant ajouté comme un dossier sans barre ; avant, il n'ajoutait rien.
- **Recherche de nouvelle version** : une case « Me signaler aussi les versions bêta et release candidates » dans Options > Affichage (désactivée par défaut). L'installeur Windows propose le même choix, avec la recherche au démarrage, parmi ses tâches.
- **Options** : la case « Mode portable » passe de l'onglet Langue à l'onglet Affichage, dans une section « Settings storage ». Le changement de mode signale maintenant une erreur quand l'ancien fichier de réglages ne peut pas être supprimé (avant, le mode ne changeait pas et rien ne le disait).
- **Nouvelle icône du programme** (fenêtre, exécutable, installeur, paquets Linux, boîte À propos), et la fenêtre À propos montre le site web du portage à côté de celui du programme d'origine.
- **Fichiers Linux signés avec GPG** (un `.asc` à côté de chaque fichier et de `SHA256SUMS-linux.txt` ; la clé publique et les commandes de vérification sont dans le README). Les fichiers Windows ne sont pas signés.
- **.deb Linux** : l'icône du menu est installée comme le thème d'icônes l'attend (SVG et PNG de 16 à 256 px).
- **Flatpak** : les fichiers d'empaquetage pour Flathub sont dans le dépôt (le paquet lui-même n'est pas encore publié).
- **Aide et documentation** : captures d'écran du programme en anglais et en français, images de la fenêtre Options refaites.

Sous le capot, le code a été relu : la compilation est sans avertissement, les lignes des listes de fichiers et du job ne portent plus de pointeurs bruts, le code de la fenêtre principale est réparti en plusieurs fichiers, les fichiers C++ suivent une seule mise en forme (`.clang-format`), et une fuite de la fenêtre Options (Annuler) est corrigée. Rien ne change dans la façon de renommer.

### Testé

Compilée et essayée sous Windows 11 (MinGW) et sous Linux, tests du moteur réussis. Le changement de langue, d'interface et de thème sans redémarrer a été vérifié sous Windows et sous Linux, avec le paquet `.deb` installé et avec l'AppImage (classique vers moderne, anglais vers français et retour, avec des fichiers dans la liste : ils restent). Le mode portable a été essayé à la main (le fichier `antrenamer-qt.ini` apparaît dans le dossier du programme quand la case est cochée et disparaît quand on la décoche). L'installeur Windows, le paquet ARM64 et le Raspberry Pi n'ont pas encore été essayés avec cette bêta : vos retours sont les bienvenus.
