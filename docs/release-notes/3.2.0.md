## Ant Renamer Qt 3.2.0

Ant Renamer Qt is a C++/Qt 6 port of [Ant Renamer](https://www.antp.be/software/renamer/) by Antoine Potten: batch file renaming (replace, insert, move, delete, enumerate, change case, regular expressions, EXIF/IPTC/XMP/ID3 tags...) on Windows and Linux.

This is the final version of 3.2.0. It is the code of 3.2.0-beta.3, unchanged. What changes since 3.1.1:

- **New action "Use EPUB info"**: name e-books from their metadata (`%author%`, `%title%`, `%year%`, `%publisher%`, `%lang%`, `%isbn%`, `%series%`, `%seriesnum%`), with its own help page, like the new "MP3 tags" page.
- **No more empty-looking names.** With the EPUB, MP3 and EXIF actions, a file whose tags give nothing to put in the name (an e-book with a blank title and author, an MP3 with empty tags) is left alone instead of being renamed to something like `- .epub`; the log says "No usable tag: the new name would be empty".
- **The Explorer menu asks what to add.** "Add to Ant Renamer Qt" shows the same window as a drop (files, folders, subfolders, hidden files), once even with several selected items. "Do not show this window again" keeps the old behaviour.
- **Files left alone are in colour**: in the preview, a file that will not be renamed is shown in orange instead of an empty "new name" cell.
- **Flatpak and documentation**: new Flatpak manifest, help and credits cleaned up (no more comparisons with the original program), links to the online help in the About window and the README.

### Tested

3.2.0-beta.2 and 3.2.0-beta.3 (the same code as this version) were published and tried by hand on Windows 11, Windows 10, Fedora (Flatpak), Linux Mint (`.deb` and AppImage) and a Raspberry Pi 4 (arm64 `.deb`): installation, upgrade over the previous version, renaming, history, EPUB renaming on real files and the fixes of the betas (empty-name fix, orange colour in the preview, Explorer window). The empty-name fix is covered by a unit test; unit tests pass and the CI is green. Your feedback is welcome.

## Ant Renamer Qt 3.2.0

Ant Renamer Qt est un portage C++/Qt 6 d'[Ant Renamer](https://www.antp.be/software/renamer/) d'Antoine Potten : renommage de fichiers par lots (remplacer, insérer, déplacer, supprimer, énumérer, changer la casse, expressions régulières, tags EXIF/IPTC/XMP/ID3...) sous Windows et Linux.

C'est la version finale de la 3.2.0. C'est le code de la 3.2.0-beta.3, sans changement. Ce qui change depuis la 3.1.1 :

- **Nouvelle opération « Infos EPUB »** : nommer des livres numériques d'après leurs métadonnées (`%author%`, `%title%`, `%year%`, `%publisher%`, `%lang%`, `%isbn%`, `%series%`, `%seriesnum%`), avec sa propre page d'aide, comme la nouvelle page « Tags MP3 ».
- **Plus de noms qui ont l'air vides.** Avec les opérations EPUB, MP3 et EXIF, un fichier dont les tags ne donnent rien à mettre dans le nom (un livre au titre et à l'auteur vides, un MP3 aux tags vides) est laissé tel quel au lieu d'être renommé en quelque chose comme `- .epub` ; le journal indique « Aucune info utilisable : le nouveau nom serait vide ».
- **Le menu de l'Explorateur demande quoi ajouter.** « Ajouter à Ant Renamer Qt » affiche la même fenêtre qu'un glisser-déposer (fichiers, dossiers, sous-dossiers, fichiers cachés), une seule fois même avec plusieurs éléments sélectionnés. « Ne plus afficher cette fenêtre » garde l'ancien comportement.
- **Les fichiers laissés tels quels sont en couleur** : dans l'aperçu, un fichier qui ne sera pas renommé est affiché en orange au lieu d'un « nouveau nom » vide.
- **Flatpak et documentation** : nouveau manifeste Flatpak, aide et crédits nettoyés (plus de comparaisons avec le programme d'origine), liens vers l'aide en ligne dans la fenêtre À propos et le README.

### Testé

Les 3.2.0-beta.2 et 3.2.0-beta.3 (le même code que cette version) ont été publiées et essayées à la main sous Windows 11, Windows 10, Fedora (Flatpak), Linux Mint (`.deb` et AppImage) et sur un Raspberry Pi 4 (`.deb` arm64) : installation, mise à jour par-dessus la version précédente, renommage, historique, renommage de vrais livres numériques et corrections des bêtas (correctif des noms vides, couleur orange de l'aperçu, fenêtre de l'Explorateur). Le correctif des noms vides est couvert par un test unitaire ; les tests unitaires réussissent et le CI est vert. Vos retours sont les bienvenus.
