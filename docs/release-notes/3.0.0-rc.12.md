## Ant Renamer Qt 3.0.0-rc.12 (release candidate)

Ant Renamer Qt is a C++/Qt 6 port of [Ant Renamer](https://www.antp.be/software/renamer/) by Antoine Potten: batch file renaming (replace, insert, move, delete, enumerate, change case, regular expressions, EXIF/IPTC/XMP/ID3 tags...) on Windows and Linux.

### What is new

- **Linux file names fixed.** A name containing a colon or a backslash (`a:b.txt`) was cut at that character, because Windows path rules were applied everywhere. On Linux only `/` delimits a path now. Same root cause fixed: the files of the list that are inside a renamed folder follow it, `%folder-N%` and the `%count%` tags work, and "Detect absolute path" recognises a name that begins with `/`. Checked on Windows and on Linux.
- **New "Modern" icon set, the default.** 30 line icons drawn by the program: sharp on any screen and screen scaling, light and dark theme, greyed when disabled. The classic sets (Scrows, Windows XP, Windows XP Large) stay in *Options > Display*. Settings saved by an older version switch to Modern once; your choice is kept afterwards.
- **The help was rewritten and checked against the program.** Markdown pages, every option and operation described (several statements of the original help were wrong for this port: regular expressions, ID3v2, date tags, fonts...), tables of tags and shortcuts, new screenshots of the real program in English and French, a picture comparing the four icon sets, and every link checked. Croatian and Tamil show the English text for the pages that were rewritten, until they are translated.
- **Guide for translators** (`docs/TRANSLATING.md`): the whole process of a `.lng` file. The **user guide** and the **recipes** (English and French) are up to date, with the differences between Windows and Linux.
- Build: a change to the help or to a language file is now copied next to the program at every build.

## Ant Renamer Qt 3.0.0-rc.12 (version candidate)

Ant Renamer Qt est un portage C++/Qt 6 d'[Ant Renamer](https://www.antp.be/software/renamer/) d'Antoine Potten : renommage de fichiers par lots (remplacer, insérer, déplacer, supprimer, énumérer, changer la casse, expressions régulières, tags EXIF/IPTC/XMP/ID3...) sous Windows et Linux.

### Nouveautés

- **Noms de fichiers corrigés sous Linux.** Un nom contenant deux-points ou antislash (`a:b.txt`) était coupé à ce caractère, car les règles de chemin de Windows s'appliquaient partout. Sous Linux seul `/` délimite un chemin maintenant. Même cause corrigée : les fichiers de la liste qui se trouvent dans un dossier renommé le suivent, `%folder-N%` et les tags `%count%` fonctionnent, et « Détecter un chemin absolu » reconnaît un nom qui commence par `/`. Vérifié sous Windows et sous Linux.
- **Nouveau jeu d'icônes « Modern », par défaut.** 30 icônes au trait dessinées par le programme : nettes sur tout écran et toute mise à l'échelle, thèmes clair et sombre, grisées quand elles sont désactivées. Les sets classiques (Scrows, Windows XP, Windows XP Large) restent dans *Options > Affichage*. Les réglages enregistrés par une ancienne version passent une fois sur Modern ; votre choix est conservé ensuite.
- **L'aide a été réécrite et vérifiée contre le programme.** Pages Markdown, chaque option et opération décrite (plusieurs affirmations de l'aide d'origine étaient fausses pour ce portage : expressions régulières, ID3v2, tags de date, polices...), tableaux des tags et des raccourcis, nouvelles captures du vrai programme en anglais et en français, une image comparant les quatre sets d'icônes, et tous les liens vérifiés. Le croate et le tamoul affichent le texte anglais pour les pages réécrites, en attendant leur traduction.
- **Guide du traducteur** (`docs/TRANSLATING_fr.md`) : tout le processus d'un fichier `.lng`. Le **guide d'utilisation** et les **recettes** (anglais et français) sont à jour, avec les différences entre Windows et Linux.
- Compilation : une modification de l'aide ou d'un fichier de langue est maintenant copiée à côté du programme à chaque compilation.
