## Ant Renamer Qt 3.1.2-beta.5

Ant Renamer Qt is a C++/Qt 6 port of [Ant Renamer](https://www.antp.be/software/renamer/) by Antoine Potten: batch file renaming (replace, insert, move, delete, enumerate, change case, regular expressions, EXIF/IPTC/XMP/ID3 tags...) on Windows and Linux.

This is a beta of 3.1.2, following 3.1.2-beta.4. What changes:

- **The new-version window shows what changes**: the release notes, in the language of the program, appear before you choose to open the download page. Only a version that has this window announces later releases this way.
- **Windows files built with MSYS2 UCRT64** instead of the deprecated MINGW64: the program uses the Windows UCRT runtime, present on Windows 10 and 11. No change is expected; tell me if the installer or the portable zip does not start.
- Comments and unused includes cleaned up in the sources (no change for the user).

It is a pre-release: it is not offered as an update to someone who runs a final version, unless they tick "Also tell me about beta and release candidates" in the options.

### What to try

Install on a machine that has no MSYS2 (installer and portable zip): the program must start. Then, once a newer version is published, the new-version window with the release notes (*About* > *Check for updates*). Please tell me what does not work, on any of your machines.

### Tested

The installer built by the CI with UCRT64 installed and tried on Windows 10 22H2. The Flatpak of 3.1.2-beta.4 tried by hand on Fedora (drag and drop, renaming, history): this version differs only by the new-version window, which a Flatpak does not use. Built on Windows 11 (MSYS2 UCRT64) with `-Werror`, tests passing. Not tried yet: the portable zip, an upgrade over 3.1.2-beta.4, the `.deb` and AppImage packages of this version. Your feedback is welcome.

## Ant Renamer Qt 3.1.2-beta.5

Ant Renamer Qt est un portage C++/Qt 6 d'[Ant Renamer](https://www.antp.be/software/renamer/) d'Antoine Potten : renommage de fichiers par lots (remplacer, insérer, déplacer, supprimer, énumérer, changer la casse, expressions régulières, tags EXIF/IPTC/XMP/ID3...) sous Windows et Linux.

C'est une bêta de la 3.1.2, qui suit la 3.1.2-beta.4. Ce qui change :

- **La fenêtre de nouvelle version montre ce qui change** : les notes de version, dans la langue du programme, s'affichent avant de décider d'ouvrir la page de téléchargement. Seule une version qui a cette fenêtre annonce les versions suivantes de cette façon.
- **Fichiers Windows construits avec MSYS2 UCRT64** au lieu de MINGW64, obsolète : le programme utilise le runtime UCRT de Windows, présent sur Windows 10 et 11. Aucun changement n'est attendu ; dites-moi si l'installeur ou le zip portable ne démarre pas.
- Commentaires et includes inutiles nettoyés dans les sources (rien ne change pour l'utilisateur).

C'est une préversion : elle n'est pas proposée comme mise à jour à quelqu'un qui utilise une version finale, sauf s'il coche « Me signaler aussi les versions bêta et release candidates » dans les options.

### Quoi essayer

Installer sur une machine sans MSYS2 (installeur et zip portable) : le programme doit démarrer. Puis, quand une version plus récente sera publiée, la fenêtre de nouvelle version avec les notes de version (*À propos* > *Rechercher une mise à jour*). Dites-moi ce qui ne marche pas, sur n'importe laquelle de vos machines.

### Testé

L'installeur construit par la CI avec UCRT64, installé et essayé sous Windows 10 22H2. Le Flatpak de la 3.1.2-beta.4 essayé à la main sous Fedora (glisser-déposer, renommage, historique) : cette version ne s'en distingue que par la fenêtre de nouvelle version, que le Flatpak n'utilise pas. Compilée sous Windows 11 (MSYS2 UCRT64) avec `-Werror`, tests réussis. Pas encore essayés : le zip portable, une mise à jour par-dessus la 3.1.2-beta.4, les paquets `.deb` et AppImage de cette version. Vos retours sont les bienvenus.
