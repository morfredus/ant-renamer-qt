## Ant Renamer Qt 3.0.0-rc.13 (release candidate)

Ant Renamer Qt is a C++/Qt 6 port of [Ant Renamer](https://www.antp.be/software/renamer/) by Antoine Potten: batch file renaming (replace, insert, move, delete, enumerate, change case, regular expressions, EXIF/IPTC/XMP/ID3 tags...) on Windows and Linux.

### What is new

- **Safer renaming.** An invalid regular expression renames nothing (the log says why); damaged MP3 tags (blank year, corrupt header) no longer cut a name or crash the program; the buttons that change the list, the batch or the options are disabled during a renaming; `*.*` also matches files without extension; a bad "Delete" no longer wipes the saved sets of the multiple string replacement.
- **Language files.** German was not valid XML and was half in English: fixed. A language file with an error is now reported instead of ignored, broken `<LINK>` and tags repaired in a dozen languages, credits completed (13 names were missing).
- **Help and documentation corrected against the program**: log colours, tag case, history size, date mask, sidecar wording; English and French vocabulary, counts and screenshots; the licence is "GPL v2 or later" everywhere.
- Build: the Windows package no longer contains test folders; the CI builds and installs the `.deb` and runs the tests on Windows too.

### Tested

By hand on Windows 11 with a test data set (photos with EXIF and sidecars, MP3 tags, odd names): actions, log, undo, saved sets, options, help. The rc.13 packages themselves, and the Linux machines, are still to be tested. See the [tested platforms](https://github.com/morfredus/ant-renamer-qt/blob/main/docs/TESTED_PLATFORMS.md).

## Ant Renamer Qt 3.0.0-rc.13 (version candidate)

Ant Renamer Qt est un portage C++/Qt 6 d'[Ant Renamer](https://www.antp.be/software/renamer/) d'Antoine Potten : renommage de fichiers par lots (remplacer, insérer, déplacer, supprimer, énumérer, changer la casse, expressions régulières, tags EXIF/IPTC/XMP/ID3...) sous Windows et Linux.

### Nouveautés

- **Renommage plus sûr.** Une expression régulière invalide ne renomme rien (le journal dit pourquoi) ; des tags MP3 abîmés (année vide, en-tête corrompu) ne coupent plus un nom et ne font plus planter le programme ; les boutons qui modifient la liste, le job ou les options sont désactivés pendant un renommage ; `*.*` accepte aussi les fichiers sans extension ; un « Supprimer » erroné n'efface plus les jeux sauvegardés du remplacement multiple.
- **Fichiers de langue.** L'allemand n'était pas du XML valide et à moitié en anglais : corrigé. Un fichier de langue en erreur est maintenant signalé au lieu d'être ignoré, liens `<LINK>` et tags cassés réparés dans une douzaine de langues, crédits complétés (13 noms manquaient).
- **Aide et documentation corrigées d'après le programme** : couleurs du journal, casse des tags, taille de l'historique, masque de date, vocabulaire des fichiers associés ; vocabulaire, comptes et captures en anglais et en français ; la licence est « GPL v2 ou ultérieure » partout.
- Compilation : le paquet Windows ne contient plus de dossiers de test ; la CI construit et installe le `.deb` et lance aussi les tests sous Windows.

### Testé

À la main sous Windows 11 avec un jeu de données de test (photos avec EXIF et fichiers associés, tags MP3, noms difficiles) : opérations, journal, annulation, jeux sauvegardés, options, aide. Les paquets rc.13 eux-mêmes et les machines Linux restent à tester. Voir les [plateformes testées](https://github.com/morfredus/ant-renamer-qt/blob/main/docs/TESTED_PLATFORMS_fr.md).
