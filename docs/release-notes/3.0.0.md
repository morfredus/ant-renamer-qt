## Ant Renamer Qt 3.0.0

Ant Renamer Qt is a C++/Qt 6 port of [Ant Renamer](https://www.antp.be/software/renamer/) by Antoine Potten: batch file renaming (replace, insert, move, delete, enumerate, change case, regular expressions, EXIF/IPTC/XMP/ID3 tags...) on Windows and Linux.

This is the first stable version of the port. It is the release candidate 16, unchanged: the only differences are the version number and a few texts of the French and English language files.

### What the port brings

Compared with Ant Renamer 2.13 (the full list is in [WHATS_NEW](https://github.com/morfredus/ant-renamer-qt/blob/main/docs/WHATS_NEW.md)):

- **Windows and Linux**: installer and portable zip for Windows, `.deb` packages (amd64, arm64: Raspberry Pi included) and an AppImage for Linux.
- **Photos**: EXIF, IPTC and XMP tags in the file names, sidecar files (`.xmp`, `.dop`) that follow their picture, the same number for a JPG and its RAW file, a `%num%` counter in the EXIF action.
- **Music**: ID3v2.2, 2.3 and 2.4 tags (the original read ID3v1 only).
- **Working in the list**: renaming history with an Undo that goes back pass after pass, "Changed only" button, natural sort (`2` before `10`), hidden and system files skipped by default, wildcards in the string replacement.
- **Interface**: light and dark theme, a "Modern" icon set, an optional modern layout with a single screen, editing an action of the batch by double-click, a help rewritten and checked against the program, a check for a new version (off by default).
- **Compatibility**: it lives next to the original (own executable and settings) and both programs read each other's `.arb` batches.

### Since 3.0.0-rc.16

No change in the program. A few texts that were still in English in the French interface are translated ("Open", "Save log", the file filters of the dialogs, "Version %1" of the About window), and the "Back" and "Forward" tips of the help window. Documentation: new presentation of the changes version by version, user guide and presentation checked against the code, security policy and code of conduct.

### Tested

The release candidate was tried on four machines: Windows 11, Linux Mint (x86-64) and two Raspberry Pi 4 with Debian 13 (arm64), from the files published on GitHub: installation over the previous version, use of the installed program, removal with the system uninstaller, then a clean installation. The program also ran under AddressSanitizer and UndefinedBehaviorSanitizer on Ubuntu 24.04 with no error, and the tests pass. Not tested: Debian 13 on x86-64, Windows 10.

## Ant Renamer Qt 3.0.0

Ant Renamer Qt est un portage C++/Qt 6 d'[Ant Renamer](https://www.antp.be/software/renamer/) d'Antoine Potten : renommage de fichiers par lots (remplacer, insérer, déplacer, supprimer, énumérer, changer la casse, expressions régulières, tags EXIF/IPTC/XMP/ID3...) sous Windows et Linux.

C'est la première version stable du portage. C'est la version candidate 16, inchangée : les seules différences sont le numéro de version et quelques textes des fichiers de langue français et anglais.

### Ce que le portage apporte

Par rapport à Ant Renamer 2.13 (la liste complète est dans [WHATS_NEW](https://github.com/morfredus/ant-renamer-qt/blob/main/docs/WHATS_NEW_fr.md)) :

- **Windows et Linux** : installeur et zip portable pour Windows, paquets `.deb` (amd64, arm64 : Raspberry Pi compris) et AppImage pour Linux.
- **Photos** : tags EXIF, IPTC et XMP dans les noms de fichiers, fichiers associés (`.xmp`, `.dop`) qui suivent leur image, même numéro pour un JPG et son fichier RAW, compteur `%num%` dans l'action EXIF.
- **Musique** : tags ID3v2.2, 2.3 et 2.4 (l'original ne lisait que l'ID3v1).
- **Travail dans la liste** : historique des renommages avec une annulation qui remonte passe après passe, bouton « Seulement modifiés », tri naturel (`2` avant `10`), fichiers cachés et système ignorés par défaut, jokers dans le remplacement de chaîne.
- **Interface** : thème clair et sombre, jeu d'icônes « Modern », disposition moderne facultative avec écran unique, modification d'une opération du job par double-clic, aide réécrite et vérifiée contre le programme, recherche de nouvelle version (désactivée par défaut).
- **Compatibilité** : il vit à côté de l'original (exécutable et réglages distincts) et les deux programmes lisent les jobs `.arb` l'un de l'autre.

### Depuis la 3.0.0-rc.16

Aucun changement dans le programme. Quelques textes qui étaient restés en anglais dans l'interface française sont traduits (« Ouvrir », « Enregistrer le journal », les filtres de fichiers des boîtes de dialogue, « Version %1 » de la fenêtre À propos), ainsi que les info-bulles « Retour » et « Suivant » de la fenêtre d'aide. Documentation : nouvelle présentation des changements version par version, guide d'utilisation et présentation vérifiés contre le code, politique de sécurité et code de conduite.

### Testé

La version candidate a été essayée sur quatre machines : Windows 11, Linux Mint (x86-64) et deux Raspberry Pi 4 sous Debian 13 (arm64), à partir des fichiers publiés sur GitHub : installation par-dessus la version précédente, utilisation du programme installé, désinstallation par le désinstalleur du système, puis installation à blanc. Le programme a aussi été exécuté sous AddressSanitizer et UndefinedBehaviorSanitizer sur Ubuntu 24.04 sans aucune erreur, et les tests passent. Pas testé : Debian 13 en x86-64, Windows 10.
