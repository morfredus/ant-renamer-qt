## Ant Renamer Qt 3.1.2-beta.4

Ant Renamer Qt is a C++/Qt 6 port of [Ant Renamer](https://www.antp.be/software/renamer/) by Antoine Potten: batch file renaming (replace, insert, move, delete, enumerate, change case, regular expressions, EXIF/IPTC/XMP/ID3 tags...) on Windows and Linux.

This is a beta of 3.1.2, an update of 3.1.1 for the Flatpak and the Windows installer. What changes:

- **Flatpak without access to the whole disk** (what the Flathub reviewers ask for): files dropped from the file manager are added again, through the document portal, and *Add folders* opens the system folder picker and lists the folders you chose (*Add folder...* and *Remove selected* buttons). On Windows and on Linux outside Flatpak, the folder tree of *Add folders* is unchanged.
- **First start after a Windows installation** shows the modern layout, even when you ticked a box of the new-version check in the installer.
- Texts of the new buttons added to the English and French language files; help page *Adding files & folders* explains the Flatpak window.

It is a pre-release: it is not offered as an update to someone who runs a final version, unless they tick "Also tell me about beta and release candidates" in the options.

### What to try

In a Flatpak: dropping files and folders from the file manager, *Add folders*. On Windows: *Add folders* (tree), first start after an installation that ticked the update-check boxes, an upgrade over 3.1.1. Please tell me what does not work, on any of your machines.

### Tested

Files dropped from the file manager tried by hand in the Flatpak on Fedora (3.1.2-beta.3: they are added again). Built on Windows 11 (MinGW) with no error. Not tried yet: the *Add folders* window in the Flatpak (3.1.2-beta.4), the installer, the `.deb` and AppImage packages of this version, an upgrade over 3.1.1. Your feedback is welcome.

## Ant Renamer Qt 3.1.2-beta.4

Ant Renamer Qt est un portage C++/Qt 6 d'[Ant Renamer](https://www.antp.be/software/renamer/) d'Antoine Potten : renommage de fichiers par lots (remplacer, insérer, déplacer, supprimer, énumérer, changer la casse, expressions régulières, tags EXIF/IPTC/XMP/ID3...) sous Windows et Linux.

C'est une bêta de la 3.1.2, mise à jour de la 3.1.1 pour le Flatpak et l'installeur Windows. Ce qui change :

- **Flatpak sans accès à tout le disque** (ce que demandent les relecteurs de Flathub) : les fichiers déposés depuis le gestionnaire de fichiers sont de nouveau ajoutés, par le portail de documents, et *Ajouter des dossiers* ouvre le sélecteur de dossier du système et liste les dossiers choisis (boutons *Ajouter un dossier...* et *Retirer la sélection*). Sous Windows et sous Linux hors Flatpak, l'arbre de dossiers d'*Ajouter des dossiers* ne change pas.
- **Premier démarrage après une installation Windows** : la disposition moderne s'affiche, même si vous avez coché une case de la recherche de nouvelle version dans l'installeur.
- Textes des nouveaux boutons ajoutés aux fichiers de langue anglais et français ; la page d'aide *Ajout de fichiers & dossiers* explique la fenêtre du Flatpak.

C'est une préversion : elle n'est pas proposée comme mise à jour à quelqu'un qui utilise une version finale, sauf s'il coche « Me signaler aussi les versions bêta et release candidates » dans les options.

### Quoi essayer

Dans un Flatpak : le dépôt de fichiers et de dossiers depuis le gestionnaire de fichiers, *Ajouter des dossiers*. Sous Windows : *Ajouter des dossiers* (arbre), le premier démarrage après une installation qui a coché les cases de recherche de mise à jour, une mise à jour par-dessus la 3.1.1. Dites-moi ce qui ne marche pas, sur n'importe laquelle de vos machines.

### Testé

Dépôt de fichiers depuis le gestionnaire de fichiers essayé à la main dans le Flatpak sous Fedora (3.1.2-beta.3 : ils sont de nouveau ajoutés). Compilée sous Windows 11 (MinGW) sans erreur. Pas encore essayés : la fenêtre *Ajouter des dossiers* dans le Flatpak (3.1.2-beta.4), l'installeur, les paquets `.deb` et AppImage de cette version, une mise à jour par-dessus la 3.1.1. Vos retours sont les bienvenus.
