## Ant Renamer Qt 3.2.0-beta.2

Ant Renamer Qt is a C++/Qt 6 port of [Ant Renamer](https://www.antp.be/software/renamer/) by Antoine Potten: batch file renaming (replace, insert, move, delete, enumerate, change case, regular expressions, EXIF/IPTC/XMP/ID3 tags...) on Windows and Linux.

This is the second beta of 3.2.0, following 3.2.0-beta.1. What changes:

- **Build fix**: the static analysis (clang-tidy) of the Linux CI job rejected one line of the EPUB reader in 3.2.0-beta.1, so the Linux packages could not be built from that commit. The line is corrected; the program works the same.
- Everything else is as in 3.2.0-beta.1: the new action "Use EPUB info" (on its own page of the Operations list, tags `%author%`, `%title%`, `%year%`, `%publisher%`, `%lang%`, `%isbn%`, `%series%`, `%seriesnum%`, option for a two-digit series number), the help section and the English and French translations.

It is a pre-release: it is not offered as an update to someone who runs a final version, unless they tick "Also tell me about beta and release candidates" in the options.

### What to try

Rename a few of your e-books with the "Use EPUB info" action and compare the preview with what you expect (EPUB files from several sources, with and without series). Tell me which files give a wrong or empty value.

### Tested

Seven real EPUB files renamed on Windows 11 (no error, with 3.2.0-beta.1). Unit tests passing. The fix itself is checked by the CI of this commit. Not tried yet: the Linux packages of this version, an upgrade over a previous beta, the Flatpak with the new manifest. Your feedback is welcome.

## Ant Renamer Qt 3.2.0-beta.2

Ant Renamer Qt est un portage C++/Qt 6 d'[Ant Renamer](https://www.antp.be/software/renamer/) d'Antoine Potten : renommage de fichiers par lots (remplacer, insérer, déplacer, supprimer, énumérer, changer la casse, expressions régulières, tags EXIF/IPTC/XMP/ID3...) sous Windows et Linux.

C'est la deuxième bêta de la 3.2.0, qui suit la 3.2.0-beta.1. Ce qui change :

- **Correction de compilation** : l'analyse statique (clang-tidy) du job Linux du CI refusait une ligne du lecteur EPUB dans la 3.2.0-beta.1, si bien que les paquets Linux ne pouvaient pas être construits à partir de ce commit. La ligne est corrigée ; le programme fonctionne de la même façon.
- Tout le reste est comme dans la 3.2.0-beta.1 : la nouvelle opération « Infos EPUB » (sur sa propre page de la liste des opérations, tags `%author%`, `%title%`, `%year%`, `%publisher%`, `%lang%`, `%isbn%`, `%series%`, `%seriesnum%`, option de numéro de série sur deux chiffres), la section d'aide et les traductions anglaise et française.

C'est une préversion : elle n'est pas proposée comme mise à jour à quelqu'un qui utilise une version finale, sauf s'il coche « Me signaler aussi les versions bêta et release candidates » dans les options.

### Quoi essayer

Renommer quelques-uns de vos livres avec l'opération « Infos EPUB » et comparer l'aperçu avec ce que vous attendez (des EPUB de plusieurs origines, avec et sans série). Dites-moi quels fichiers donnent une valeur fausse ou vide.

### Testé

Sept vrais fichiers EPUB renommés sous Windows 11 (aucune erreur, avec la 3.2.0-beta.1). Tests unitaires réussis. La correction elle-même est vérifiée par le CI de ce commit. Pas encore essayés : les paquets Linux de cette version, une mise à jour par-dessus une bêta précédente, le Flatpak avec le nouveau manifeste. Vos retours sont les bienvenus.
