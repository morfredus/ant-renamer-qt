## Ant Renamer Qt 3.0.0-rc.11 (release candidate)

Ant Renamer Qt is a C++/Qt 6 port of [Ant Renamer](https://www.antp.be/software/renamer/) by Antoine Potten: batch file renaming (replace, insert, move, delete, enumerate, change case, regular expressions, EXIF/IPTC/XMP/ID3 tags...) on Windows and Linux.

### What is new

- **Linux package fixed for Debian 13.** The `.deb` could not be installed on Debian 13 (`libqt6gui6t64 is only referenced by name`): its dependencies carried the Ubuntu 24.04 names. They now accept both the Ubuntu and the Debian names. Checked on Debian 13 (trixie) arm64 (Raspberry Pi 4: package installed from the `.deb`, program working) and on Ubuntu 24.04 (build and dependency list); Debian 13 x86-64 users, please tell us if the install works. See the [tested platforms](https://github.com/morfredus/ant-renamer-qt/blob/main/docs/TESTED_PLATFORMS.md).
- **Native Wayland.** The `.deb` now recommends `qt6-wayland`, so apt installs the Wayland platform plugin by default (without it the program runs through XWayland).
- No change for Windows in this release.

## Ant Renamer Qt 3.0.0-rc.11 (version candidate)

Ant Renamer Qt est un portage C++/Qt 6 d'[Ant Renamer](https://www.antp.be/software/renamer/) d'Antoine Potten : renommage de fichiers par lots (remplacer, insérer, déplacer, supprimer, énumérer, changer la casse, expressions régulières, tags EXIF/IPTC/XMP/ID3...) sous Windows et Linux.

### Nouveautés

- **Paquet Linux corrigé pour Debian 13.** Le `.deb` ne s'installait pas sous Debian 13 (`libqt6gui6t64 is only referenced by name`) : ses dépendances portaient les noms d'Ubuntu 24.04. Elles acceptent maintenant les noms d'Ubuntu et de Debian. Vérifié sur Debian 13 (trixie) arm64 (Raspberry Pi 4 : paquet installé depuis le `.deb`, programme fonctionnel) et sur Ubuntu 24.04 (compilation et liste des dépendances) ; les utilisateurs de Debian 13 en x86-64 sont invités à dire si l'installation passe. Voir les [plateformes testées](https://github.com/morfredus/ant-renamer-qt/blob/main/docs/TESTED_PLATFORMS_fr.md).
- **Wayland natif.** Le `.deb` recommande maintenant `qt6-wayland` : apt installe le plugin Wayland par défaut (sinon le programme passe par XWayland).
- Aucun changement pour Windows dans cette version.
