## Ant Renamer Qt 3.1.1-beta.1

Ant Renamer Qt is a C++/Qt 6 port of [Ant Renamer](https://www.antp.be/software/renamer/) by Antoine Potten: batch file renaming (replace, insert, move, delete, enumerate, change case, regular expressions, EXIF/IPTC/XMP/ID3 tags...) on Windows and Linux.

This is a beta of 3.1.1, the first update of the stable 3.1.0. What changes:

- **Date and time and EXIF actions number the files given the same name** (`_01`, `_02`... in the order of the shooting): a burst shot in the same second no longer ends with refused files. New option *Number files given the same name* (Processing, on by default). The old *Add suffix* box of Date and time is removed.
- **One window at a time**: a second launch shows an information box and quits (two windows overwrote each other's undo history and settings). With `-g` or `-x` it prints a message and returns the exit code 3.
- **Adding a folder with no file** says "No file found in ..." in a message box, the status bar and the log.
- **Linux AppImage**: update information embedded, so AppImageUpdate can update it.
- Screenshots of the help remade with the 3.1 interface.

It is a pre-release: it is not offered as an update to someone who runs a final version, unless they tick "Also tell me about beta and release candidates" in the options.

### What to try

The numbering with a burst of photos (Date and time, EXIF), in the preview and in the real renaming; a second launch of the program while a window is open (from the menu, from a shortcut, from a script with `-g -x`); adding an empty folder; an upgrade over 3.1.0. Please tell me what does not work, on any of your machines.

### Tested

Tried by hand on Windows 11 and on a Raspberry Pi 4 (Debian 13, arm64): the second launch (message, then the second window closes), the message for an added folder that holds no file (Windows: Add folders button and drag and drop), and on the Pi the numbering of files given the same name. Built from the source with no compiler warning (`-Werror`) and the unit and panel tests passing on Windows 11 (MinGW), Ubuntu 24.04 (WSL2) and the Pi; clang-tidy finds nothing on the three. Not tried yet: the installer, the `.deb` and AppImage packages of this version, an upgrade over 3.1.0, Linux Mint and the other Pi. Your feedback is welcome.

## Ant Renamer Qt 3.1.1-beta.1

Ant Renamer Qt est un portage C++/Qt 6 d'[Ant Renamer](https://www.antp.be/software/renamer/) d'Antoine Potten : renommage de fichiers par lots (remplacer, insérer, déplacer, supprimer, énumérer, changer la casse, expressions régulières, tags EXIF/IPTC/XMP/ID3...) sous Windows et Linux.

C'est une bêta de la 3.1.1, première mise à jour de la 3.1.0 stable. Ce qui change :

- **Les actions Date et heure et EXIF numérotent les fichiers qui reçoivent le même nom** (`_01`, `_02`... dans l'ordre de prise de vue) : une rafale prise dans la même seconde ne finit plus avec des fichiers refusés. Nouvelle option *Numéroter les fichiers qui reçoivent le même nom* (Traitement, cochée par défaut). L'ancienne case *Ajouter un suffixe* de Date et heure disparaît.
- **Une seule fenêtre à la fois** : un deuxième lancement affiche une boîte d'information et quitte (deux fenêtres écrasaient mutuellement l'historique d'annulation et les réglages). Avec `-g` ou `-x`, il écrit un message et rend le code de sortie 3.
- **Ajouter un dossier sans fichier** affiche « Aucun fichier trouvé dans ... » dans une boîte de message, la barre d'état et le journal.
- **AppImage Linux** : informations de mise à jour intégrées, AppImageUpdate peut donc le mettre à jour.
- Captures d'écran de l'aide refaites avec l'interface de la 3.1.

C'est une préversion : elle n'est pas proposée comme mise à jour à quelqu'un qui utilise une version finale, sauf s'il coche « Me signaler aussi les versions bêta et release candidates » dans les options.

### Quoi essayer

La numérotation avec une rafale de photos (Date et heure, EXIF), dans l'aperçu et au vrai renommage ; un deuxième lancement du programme alors qu'une fenêtre est ouverte (depuis le menu, un raccourci, un script avec `-g -x`) ; l'ajout d'un dossier vide ; une mise à jour par-dessus la 3.1.0. Dites-moi ce qui ne marche pas, sur n'importe laquelle de vos machines.

### Testé

Essayée à la main sous Windows 11 et sur un Raspberry Pi 4 (Debian 13, arm64) : le deuxième lancement (message, puis la deuxième fenêtre se ferme), le message pour un dossier ajouté qui ne contient aucun fichier (Windows : bouton Ajouter des dossiers et glisser-déposer), et sur le Pi la numérotation des fichiers qui reçoivent le même nom. Compilée depuis les sources sans aucun avertissement (`-Werror`), tests unitaires et du panneau réussis sous Windows 11 (MinGW), Ubuntu 24.04 (WSL2) et sur le Pi ; clang-tidy ne trouve rien sur les trois. Pas encore essayés : l'installeur, les paquets `.deb` et AppImage de cette version, une mise à jour par-dessus la 3.1.0, Linux Mint et l'autre Pi. Vos retours sont les bienvenus.
