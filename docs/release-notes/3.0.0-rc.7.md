## Ant Renamer Qt 3.0.0-rc.7 (release candidate)

Ant Renamer Qt is a C++/Qt 6 port of [Ant Renamer](https://www.antp.be/software/renamer/) by Antoine Potten: batch file renaming (replace, insert, move, delete, enumerate, change case, regular expressions, EXIF/ID3 tags...) on Windows and Linux.

### What is new

- **Natural sort in the Files list.** Clicking a column header now sorts `file 2` before `file 10` instead of `file 1`, `file 10`, `file 100`, `file 11`... This is the default. If you prefer the alphabetical order of the original program, untick *Options > Display > Natural sort in files list*.
- **Sorting works every time.** After the first click on a column header, clicking any header no longer sorted the list: fixed.

## Ant Renamer Qt 3.0.0-rc.7 (version candidate)

Ant Renamer Qt est un portage C++/Qt 6 d'[Ant Renamer](https://www.antp.be/software/renamer/) d'Antoine Potten : renommage de fichiers par lots (remplacer, insérer, déplacer, supprimer, énumérer, changer la casse, expressions régulières, tags EXIF/ID3...) sous Windows et Linux.

### Nouveautés

- **Tri naturel dans la liste des fichiers.** Un clic sur un en-tête de colonne trie maintenant `fichier 2` avant `fichier 10`, au lieu de `fichier 1`, `fichier 10`, `fichier 100`, `fichier 11`... C'est le comportement par défaut. Si vous préférez l'ordre alphabétique du programme d'origine, décochez *Options > Affichage > Tri naturel dans la liste des fichiers*.
- **Le tri fonctionne à chaque clic.** Après le premier clic sur un en-tête de colonne, les clics suivants ne triaient plus la liste : corrigé.
