## Ant Renamer Qt 3.0.0-rc.9 (release candidate)

Ant Renamer Qt is a C++/Qt 6 port of [Ant Renamer](https://www.antp.be/software/renamer/) by Antoine Potten: batch file renaming (replace, insert, move, delete, enumerate, change case, regular expressions, EXIF/IPTC/XMP/ID3 tags...) on Windows and Linux.

### What is new

- **IPTC and XMP data in the EXIF action.** Keywords, title, caption, author, place, rating, color label... can be used in the mask like the EXIF tags: `%IptcKeywords%`, `%XmpTitle%`, `%XmpRating%`... IPTC is read from JPEG files, XMP from any file that embeds it (JPEG, PNG, WebP, TIFF, DNG) and from `.xmp` files. A new help page lists every usable tag, with tips (taking IPTC or XMP with `$if`, dates, several values).
- **Sidecar files follow their picture.** Renaming `IMG.CR2` (or the JPG) also renames its `.xmp` (`IMG.xmp` or `IMG.CR2.xmp`: Lightroom, Capture One, digiKam, darktable) and its DxO PhotoLab `.dop`, and the revert puts them back. On by default (*Options > Processing*), so a rename never leaves an orphan sidecar. The XMP sidecar is also read by the EXIF action, so the keywords and rating you gave to a RAW file are usable in the mask.
- **"Changed only" button** in the files list: hides the files whose name does not change in the preview, ideal to review the few files concerned in a big list. It is only a view filter: hidden files stay in the list and are renamed as usual.
- **Wildcards in String replacement**: new "Use wildcards" option. `*` stands for any text, `?` for any single character.
- **Same number for JPG + RAW pairs**: new optional box in Enumeration and EXIF, so `IMG_1234.JPG` and `IMG_1234.CR2` (and the XMP) get the same number.
- **Action editor**: the notes and the check box texts wrap to the panel width instead of being cut by a horizontal scroll bar.

The IPTC and XMP readers were checked with a synthetic JPEG; feedback with real photos (Lightroom, Capture One, digiKam...) is very welcome.

## Ant Renamer Qt 3.0.0-rc.9 (version candidate)

Ant Renamer Qt est un portage C++/Qt 6 d'[Ant Renamer](https://www.antp.be/software/renamer/) d'Antoine Potten : renommage de fichiers par lots (remplacer, insérer, déplacer, supprimer, énumérer, changer la casse, expressions régulières, tags EXIF/IPTC/XMP/ID3...) sous Windows et Linux.

### Nouveautés

- **Données IPTC et XMP dans l'action EXIF.** Mots-clés, titre, légende, auteur, lieu, note, label de couleur... s'utilisent dans le masque comme les tags EXIF : `%IptcKeywords%`, `%XmpTitle%`, `%XmpRating%`... L'IPTC est lu dans les fichiers JPEG, le XMP dans tout fichier qui le contient (JPEG, PNG, WebP, TIFF, DNG) et dans les fichiers `.xmp`. Une nouvelle page d'aide liste tous les tags utilisables, avec des conseils (prendre l'IPTC ou le XMP avec `$if`, dates, valeurs multiples).
- **Les fichiers associés suivent leur image.** Renommer `IMG.CR2` (ou le JPG) renomme aussi son `.xmp` (`IMG.xmp` ou `IMG.CR2.xmp` : Lightroom, Capture One, digiKam, darktable) et son `.dop` de DxO PhotoLab, et l'annulation les remet. Activé par défaut (*Options > Traitement*), pour qu'un renommage ne laisse jamais de fichier associé orphelin. Le fichier XMP associé est aussi lu par l'action EXIF : les mots-clés et la note donnés à un fichier RAW sont utilisables dans le masque.
- **Bouton « Seulement modifiés »** dans la liste des fichiers : masque les fichiers dont le nom ne change pas dans l'aperçu, idéal pour contrôler les quelques fichiers concernés dans une grosse liste. C'est un simple filtre d'affichage : les fichiers masqués restent dans la liste et sont renommés normalement.
- **Jokers dans le remplacement de chaîne** : nouvelle option « Utiliser les jokers ». `*` remplace n'importe quel texte, `?` un seul caractère.
- **Même numéro pour les paires JPG + RAW** : nouvelle case optionnelle dans Énumération et EXIF, pour que `IMG_1234.JPG` et `IMG_1234.CR2` (et le XMP) reçoivent le même numéro.
- **Éditeur d'actions** : les notes et les textes des cases à cocher passent à la ligne selon la largeur du panneau au lieu d'être coupés par une barre de défilement horizontale.

Les lecteurs IPTC et XMP ont été vérifiés avec un JPEG synthétique ; vos retours avec de vraies photos (Lightroom, Capture One, digiKam...) sont très bienvenus.
