## Ant Renamer Qt 3.0.0-rc.15 (release candidate)

Ant Renamer Qt is a C++/Qt 6 port of [Ant Renamer](https://www.antp.be/software/renamer/) by Antoine Potten: batch file renaming (replace, insert, move, delete, enumerate, change case, regular expressions, EXIF/IPTC/XMP/ID3 tags...) on Windows and Linux.

### What is new

Since rc.12, the last published candidate (rc.13 and rc.14 were test builds):

- **Light / dark theme.** A new button in the toolbar (half-filled circle) switches at once between the light and the dark theme, and *Options > Display > Theme* offers "Follow the system" (default), "Light" and "Dark". It works on every system, including the AppImage, which cannot detect the theme of the desktop. In a dark theme the log lines, the toolbar highlight and the tool tips are readable.
- **Safer renaming.** An invalid regular expression renames nothing (the log says why). Damaged MP3 tags (blank year, corrupt header) no longer cut a name or crash the program. The buttons that change the list, the batch or the options are disabled during a renaming. `*.*` also matches files without extension. A wrong "Delete" no longer wipes the saved sets of the multiple string replacement.
- **Language files.** German was not valid XML and was half in English: fixed. A language file with an error is now reported instead of silently ignored; broken `<LINK>` and tags repaired in a dozen languages; credits completed (13 names were missing). The texts that only the French interface had (portable mode, theme, the *About* window, sidecar files...) are now in the language files (section `<QtPort>` of `English.lng`): add the same lines to your `.lng` file to translate them. The French interface is unchanged.
- **Help and documentation corrected against the program**: log colours, case of the tags, size of the history, date mask, sidecar wording; English and French vocabulary, counts and screenshots; the licence is "GPL v2 or later" everywhere and the AppImage carries it.
- **Build and packaging.** The Windows package no longer contains test folders; the AppImage tools are pinned to a release and checked by SHA-256; the CI builds and installs the `.deb`, runs the tests and no longer hangs on Windows; the Windows build tries a second time when a file is locked; bilingual issue templates.

### Tested

The rc.15 packages were installed and run on four machines: Windows 11 (installer and portable zip), Linux Mint (x86-64, `.deb` and AppImage) and two Raspberry Pi 4 with Debian 13 (arm64). Checked on all of them: renaming of files, pictures, sidecar files and folders, the light / dark switch (AppImage included) and the readable log and tool tips in the dark theme. Not tested: Debian 13 on x86-64, Windows 10. See the [tested platforms](https://github.com/morfredus/ant-renamer-qt/blob/main/docs/TESTED_PLATFORMS.md).

## Ant Renamer Qt 3.0.0-rc.15 (version candidate)

Ant Renamer Qt est un portage C++/Qt 6 d'[Ant Renamer](https://www.antp.be/software/renamer/) d'Antoine Potten : renommage de fichiers par lots (remplacer, insérer, déplacer, supprimer, énumérer, changer la casse, expressions régulières, tags EXIF/IPTC/XMP/ID3...) sous Windows et Linux.

### Nouveautés

Depuis la rc.12, dernière version candidate publiée (les rc.13 et rc.14 étaient des versions de test) :

- **Thème clair / sombre.** Un nouveau bouton de la barre d'outils (cercle à moitié plein) passe aussitôt du thème clair au thème sombre, et *Options > Affichage > Thème* propose « Suivre le système » (par défaut), « Clair » et « Sombre ». Cela fonctionne sur tous les systèmes, y compris l'AppImage, qui ne peut pas détecter le thème du bureau. En thème sombre, les lignes du journal, la surbrillance de la barre d'outils et les info-bulles sont lisibles.
- **Renommage plus sûr.** Une expression régulière invalide ne renomme rien (le journal dit pourquoi). Des tags MP3 abîmés (année vide, en-tête corrompu) ne coupent plus un nom et ne font plus planter le programme. Les boutons qui modifient la liste, le job ou les options sont désactivés pendant un renommage. `*.*` accepte aussi les fichiers sans extension. Un « Supprimer » erroné n'efface plus les jeux sauvegardés du remplacement multiple.
- **Fichiers de langue.** L'allemand n'était pas du XML valide et à moitié en anglais : corrigé. Un fichier de langue en erreur est maintenant signalé au lieu d'être ignoré en silence ; liens `<LINK>` et tags cassés réparés dans une douzaine de langues ; crédits complétés (13 noms manquaient). Les textes que seule l'interface française avait (mode portable, thème, fenêtre *À propos*, fichiers associés...) sont maintenant dans les fichiers de langue (section `<QtPort>` de `English.lng`) : ajoutez les mêmes lignes à votre fichier `.lng` pour les traduire. L'interface française ne change pas.
- **Aide et documentation corrigées d'après le programme** : couleurs du journal, casse des tags, taille de l'historique, masque de date, vocabulaire des fichiers associés ; vocabulaire, comptes et captures en anglais et en français ; la licence est « GPL v2 ou ultérieure » partout et l'AppImage la contient.
- **Compilation et paquets.** Le paquet Windows ne contient plus de dossiers de test ; les outils de l'AppImage sont épinglés à une version et vérifiés par SHA-256 ; la CI construit et installe le `.deb`, lance les tests et ne se bloque plus sous Windows ; la compilation Windows réessaie une fois quand un fichier est verrouillé ; modèles de tickets bilingues.

### Testé

Les paquets rc.15 ont été installés et lancés sur quatre machines : Windows 11 (installeur et zip portable), Linux Mint (x86-64, `.deb` et AppImage) et deux Raspberry Pi 4 sous Debian 13 (arm64). Vérifié sur toutes : renommage de fichiers, d'images, de fichiers associés et de dossiers, bascule clair / sombre (AppImage comprise), journal et info-bulles lisibles en thème sombre. Pas testé : Debian 13 en x86-64, Windows 10. Voir les [plateformes testées](https://github.com/morfredus/ant-renamer-qt/blob/main/docs/TESTED_PLATFORMS_fr.md).
