## Ant Renamer Qt 3.0.0-rc.16 (release candidate)

Ant Renamer Qt is a C++/Qt 6 port of [Ant Renamer](https://www.antp.be/software/renamer/) by Antoine Potten: batch file renaming (replace, insert, move, delete, enumerate, change case, regular expressions, EXIF/IPTC/XMP/ID3 tags...) on Windows and Linux.

### What is new

Since rc.15:

- **Hidden and system files.** Adding a folder used to list everything in it, including `desktop.ini`, `.git` and the like. Now they are skipped, unless you tick the new option *Options > Files & Folders > Include hidden and system files when adding a folder* (off by default). A file you pick or drop on its own is always added. A new **Hidden files** button in the list shows or hides them; while hidden, no operation touches them. Before a renaming, a warning (Yes / No, "No" by default) appears if the list holds hidden or system files.
- **Renaming history.** Every action of a batch run with *Go* is now a pass kept for the session. **Undo** (F12) no longer stops at the last renaming: it goes back pass after pass, always from the last one, and the new **History** button (Shift+F12) lists the passes and goes back to the one you choose, undoing it and all those after it (never one in the middle). A file moved outside the program stops the undo there. The last 50 passes are kept, until the program is closed. *Options > Files & Folders > The Undo button* makes the Undo button open the history instead. French interface included.
- **New-version check** (off by default). *Options > Display > Look for a new version at start* asks GitHub once a day whether a newer release exists, and the new "Check for updates" button of the About window does it on demand. Nothing but an ordinary request is sent; if GitHub cannot be reached, nothing happens and the program works as usual.
- **Light theme** fixes: an explicit light palette (a dark desktop made "Light" dark with a system Qt), and the links follow the theme.

### Tested

The new features were tried on four machines: Windows 11, Linux Mint (x86-64) and two Raspberry Pi 4 with Debian 13 (arm64). Checked on all of them: the hidden and system files and folders shown or hidden (option, button and import windows), the warning before a renaming, and renaming itself, plus the renaming history (several undos in a row, the History window, going back several passes at once, the option of the Undo button, in English and in French). Not tested: Debian 13 on x86-64, Windows 10.

## Ant Renamer Qt 3.0.0-rc.16 (version candidate)

Ant Renamer Qt est un portage C++/Qt 6 d'[Ant Renamer](https://www.antp.be/software/renamer/) d'Antoine Potten : renommage de fichiers par lots (remplacer, insérer, déplacer, supprimer, énumérer, changer la casse, expressions régulières, tags EXIF/IPTC/XMP/ID3...) sous Windows et Linux.

### Nouveautés

Depuis la rc.15 :

- **Fichiers cachés et système.** L'ajout d'un dossier listait tout son contenu, y compris `desktop.ini`, `.git` et consorts. Ils sont maintenant ignorés, sauf si vous cochez la nouvelle option *Options > Fichiers & Dossiers > Inclure les fichiers cachés et système à l'ajout d'un dossier* (désactivée par défaut). Un fichier choisi ou déposé seul est toujours ajouté. Un nouveau bouton **Fichiers cachés** de la liste les affiche ou les masque ; tant qu'ils sont masqués, aucune opération ne les touche. Avant un renommage, un avertissement (Oui / Non, « Non » par défaut) s'affiche si la liste contient des fichiers cachés ou système.
- **Historique des renommages.** Chaque opération d'un job lancé avec *Démarrer* est maintenant une passe gardée pour la session. **Annuler** (F12) ne s'arrête plus au dernier renommage : il remonte passe après passe, toujours à partir de la dernière, et le nouveau bouton **Historique** (Maj+F12) liste les passes et revient à celle que vous choisissez, en l'annulant avec toutes les suivantes (jamais une passe au milieu). Un fichier déplacé en dehors du programme arrête l'annulation à cet endroit. Les 50 dernières passes sont gardées, jusqu'à la fermeture du programme. *Options > Fichiers & Dossiers > Le bouton Annuler* fait ouvrir l'historique par le bouton Annuler. Interface en français comprise.
- **Recherche de nouvelle version** (désactivée par défaut). *Options > Affichage > Rechercher une nouvelle version au démarrage* demande à GitHub une fois par jour s'il existe une version plus récente, et le nouveau bouton « Rechercher une mise à jour » de la fenêtre À propos le fait à la demande. Seule une requête ordinaire est envoyée ; si GitHub est inaccessible, il ne se passe rien et le programme fonctionne comme d'habitude.
- **Thème clair** corrigé : palette claire explicite (un bureau sombre rendait le thème « Clair » sombre avec un Qt système), et les liens suivent le thème.

### Testé

Les nouveautés ont été essayées sur quatre machines : Windows 11, Linux Mint (x86-64) et deux Raspberry Pi 4 sous Debian 13 (arm64). Vérifié sur toutes : affichage ou masquage des fichiers et dossiers cachés et système (option, bouton et fenêtres d'importation), avertissement avant un renommage, et renommage lui-même, plus l'historique des renommages (plusieurs annulations de suite, fenêtre Historique, retour de plusieurs passes à la fois, option du bouton Annuler, en anglais et en français). Pas testé : Debian 13 en x86-64, Windows 10.
