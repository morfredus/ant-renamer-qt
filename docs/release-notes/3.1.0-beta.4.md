## Ant Renamer Qt 3.1.0-beta.4

Ant Renamer Qt is a C++/Qt 6 port of [Ant Renamer](https://www.antp.be/software/renamer/) by Antoine Potten: batch file renaming (replace, insert, move, delete, enumerate, change case, regular expressions, EXIF/IPTC/XMP/ID3 tags...) on Windows and Linux.

This is the fourth beta of 3.1, the version that follows the stable 3.0.0. It is a beta: it is published to be tried, and it is not offered as an update to someone who runs a final version, unless they tick "Also tell me about beta and release candidates" in the options.

### What is new since 3.1.0-beta.3

- **The undo history is kept when the program is closed.** Start the program again, and **Undo** (F12) or **History** (Shift+F12) still go back through the last 50 passes, even the next day. The passes are grouped by session (one run of the program): you undo a session without touching the later ones. Before undoing a file, the program checks that it still has the size and the date it had after the renaming; if it was moved, deleted, replaced or edited outside the program, the undo stops there. A *Clear the history* button forgets everything. The history is saved in `antrenamer-qt-history.json`, next to the settings file (in the program folder for the portable version).
- **Silent command line**: `-q` runs a job with no window and no dialog, for scripts and context menus. The exit code says how it went: 0 done, 1 at least one file failed, 2 nothing done.
- **The modern layout is the default of a new installation** (single screen, in bands). Nothing changes for anyone who already has settings: they keep their layout, and the classic one stays one click away (Options > Display).
- **End of a renaming**: the log and the status bar say how many files were renamed and how many failed.
- **String replacement**: *Only at the beginning* is now the default choice, and *Anywhere in the name* comes last. The saved jobs are not changed.
- **Fields of the actions**: the first click in a field selects the whole text, so the "old" and "new" samples are replaced by typing.
- **Add folders**: a *Paste from clipboard* button for the path of a folder (the quotes of Explorer's "Copy as path" are removed).
- **The window keeps its size after a language change** (second try: a tester still saw it come back small with beta.3).
- **Help and translations**: a help page that a language does not have is shown in English; eight messages that were only in English are now translated in French; the English and French documents were checked against the program.

Most of this came from the feedback of the first users. The Croatian and Tamil help pages and texts show English for these additions.

### Tested

Built on Windows 11 (MinGW) with the engine and panel tests passing. The undo history by session was tried by hand on Windows, and so were the silent command line (exit codes, missing job) and the modern layout on a first start. The end-of-renaming message, the new default of the string replacement, the selection on the first click, the Paste button and the window size after a language change have not been tried by hand yet. The Linux packages, the Windows installer, the ARM64 package and the Raspberry Pi have not been tried with this beta: your feedback is welcome.

## Ant Renamer Qt 3.1.0-beta.4

Ant Renamer Qt est un portage C++/Qt 6 d'[Ant Renamer](https://www.antp.be/software/renamer/) d'Antoine Potten : renommage de fichiers par lots (remplacer, insérer, déplacer, supprimer, énumérer, changer la casse, expressions régulières, tags EXIF/IPTC/XMP/ID3...) sous Windows et Linux.

C'est la quatrième bêta de la 3.1, la version qui suit la 3.0.0 stable. C'est une bêta : elle est publiée pour être essayée, et elle n'est pas proposée comme mise à jour à quelqu'un qui utilise une version finale, sauf s'il coche « Me signaler aussi les versions bêta et release candidates » dans les options.

### Nouveautés depuis la 3.1.0-beta.3

- **L'historique d'annulation est conservé à la fermeture du programme.** Relancez le programme : **Annuler** (F12) ou **Historique** (Maj+F12) remontent encore les 50 dernières passes, même le lendemain. Les passes sont regroupées par session (un lancement du programme) : on annule une session sans toucher aux suivantes. Avant d'annuler un fichier, le programme vérifie qu'il a toujours la taille et la date qu'il avait après le renommage ; s'il a été déplacé, supprimé, remplacé ou modifié en dehors du programme, l'annulation s'arrête là. Un bouton *Effacer l'historique* oublie tout. L'historique est enregistré dans `antrenamer-qt-history.json`, à côté du fichier de réglages (dans le dossier du programme pour la version portable).
- **Ligne de commande silencieuse** : `-q` exécute un job sans fenêtre ni boîte de dialogue, pour les scripts et les menus contextuels. Le code de sortie dit comment cela s'est passé : 0 fait, 1 au moins un fichier a échoué, 2 rien n'a été fait.
- **La disposition moderne est celle d'une nouvelle installation** (écran unique, en bandes). Rien ne change pour qui a déjà des réglages : la disposition choisie est conservée, et la classique reste à un clic (Options > Affichage).
- **Fin d'un renommage** : le journal et la barre d'état disent combien de fichiers ont été renommés et combien ont échoué.
- **Remplacement de chaîne** : *Seulement au début* est maintenant le choix par défaut, et *N'importe où dans le nom* vient en dernier. Les jobs enregistrés ne changent pas.
- **Champs des opérations** : le premier clic dans un champ sélectionne tout le texte, les exemples « old » et « new » se remplacent donc en tapant.
- **Ajouter des dossiers** : un bouton *Coller depuis le presse-papiers* pour le chemin d'un dossier (les guillemets du « Copier en tant que chemin » de l'Explorateur sont retirés).
- **La fenêtre garde sa taille après un changement de langue** (deuxième essai : un testeur la voyait encore revenir en petit avec la bêta.3).
- **Aide et traductions** : une page d'aide absente dans une langue s'affiche en anglais ; huit messages qui n'existaient qu'en anglais sont traduits en français ; les documents anglais et français ont été vérifiés par rapport au programme.

La plupart de ces changements viennent des retours des premiers utilisateurs. Les pages d'aide et les textes en croate et en tamoul montrent l'anglais pour ces ajouts.

### Testé

Compilée sous Windows 11 (MinGW), tests du moteur et du panneau réussis. L'historique d'annulation par session a été essayé à la main sous Windows, ainsi que la ligne de commande silencieuse (codes de sortie, job manquant) et la disposition moderne au premier lancement. Le message de fin de renommage, le nouveau choix par défaut du remplacement de chaîne, la sélection au premier clic, le bouton Coller et la taille de la fenêtre après un changement de langue n'ont pas encore été essayés à la main. Les paquets Linux, l'installeur Windows, le paquet ARM64 et le Raspberry Pi n'ont pas été essayés avec cette bêta : vos retours sont les bienvenus.
