# Plateformes testées

Où Ant Renamer Qt a réellement été compilé et lancé. « Testé » veut dire qu'une personne a lancé le programme ou le paquet sur ce système ; une plateforme absente de la liste n'a pas été testée, même si elle devrait fonctionner. ([English version](TESTED_PLATFORMS.md).)

Si vous essayez un autre système, merci de donner le résultat dans les [discussions](https://github.com/morfredus/ant-renamer-qt/discussions) (ça marche ou non, avec la version et le système).

| Système | Architecture | Version | Ce qui a été testé |
|---|---|---|---|
| Debian GNU/Linux 13 (trixie), Raspberry Pi 4 Model B (deux machines) | arm64 | 3.0.0-rc.11, rc.12, rc.13, rc.14, rc.15, rc.16 | rc.11 : `.deb` installé depuis le paquet (dépendances résolues par apt), entrée de menu présente, programme fonctionnel, interface en français. rc.12 : `.deb` arm64 installé depuis le paquet, programme fonctionnel, noms de fichiers Linux, pages d'aide et liens, jeux d'icônes et lisibilité. rc.13, rc.14 : installé depuis les paquets, le programme fonctionne ; rc.14 : bascule clair / sombre, journal lisible en thème sombre. rc.15 : `.deb` installé depuis le paquet ; renommage de fichiers, d'images, de fichiers associés et de dossiers, bascule clair / sombre, journal et info-bulles lisibles en thème sombre. rc.16 (brouillon) : les nouveautés, sur cette machine aussi : fichiers cachés et système, et historique des renommages (Annuler passe après passe, fenêtre Historique, option du bouton Annuler, interface en français). |
| Linux Mint 22.3 Xfce (base Ubuntu 24.04) | x86-64 | 3.0.0-rc.11, rc.12, rc.13, rc.14, rc.15, rc.16 | rc.11 : `.deb` installé depuis le paquet, programme fonctionnel. rc.12 : `.deb` installé depuis le paquet ; noms de fichiers Linux (`:`, `/`, renommage de dossier, `%folder-N%`, `%count%`), pages d'aide et liens, jeux d'icônes et lisibilité. rc.13, rc.14 : installé depuis le `.deb`, le programme fonctionne ; rc.14 : l'AppImage se lance et fonctionne, bascule clair / sombre (AppImage comprise), journal lisible en thème sombre. rc.15 : `.deb` et AppImage installés et lancés ; renommage de fichiers, d'images, de fichiers associés et de dossiers, bascule clair / sombre (AppImage comprise). rc.16 (brouillon) : les nouveautés, sur cette machine aussi : fichiers cachés et système, et historique des renommages (Annuler passe après passe, fenêtre Historique, option du bouton Annuler, interface en français). |
| Ubuntu 24.04 (WSL2 sous Windows 11) | x86-64 | 3.0.0-rc.10, rc.11 | compilation, tests unitaires, `.deb` et AppImage construits ; programme démarré, aide affichée ; liste de dépendances du `.deb` vérifiée (`ldd` : aucune bibliothèque manquante) |

## Pas encore testé

- Debian 13 en x86-64 (le correctif de dépendances de rc.11 est le même qu'en arm64, mais le paquet amd64 n'y a pas été installé).
- Toute autre distribution avec l'AppImage (testée sur la machine Linux Mint seulement), Windows 10, macOS (non pris en charge).

Mettre ce fichier à jour à chaque release : version, système, ce qui a été vérifié.
