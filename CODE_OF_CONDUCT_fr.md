# Code de conduite

([English version](CODE_OF_CONDUCT.md))

Ce projet suit l'esprit du [Contributor Covenant 2.1](https://www.contributor-covenant.org/fr/version/2/1/code_of_conduct/), en version courte.

## Notre engagement

Nous voulons que la participation à ce projet (issues, discussions, pull requests, traductions) soit une expérience respectueuse et sans harcèlement pour tout le monde, quels que soient l'âge, le corps, le handicap, l'origine ethnique, l'identité de genre, l'expérience, la nationalité, l'apparence, la religion, l'identité et l'orientation sexuelles.

## Comportements attendus

- Être bienveillant et patient, surtout avec les personnes qui découvrent le projet ou la programmation.
- Respecter les autres points de vue ; critiquer le code ou l'idée, jamais la personne.
- Donner et accepter les remarques constructives avec élégance.
- Assumer ses erreurs et en tirer des leçons.

## Comportements inacceptables

- Insultes, attaques personnelles, provocations, langage ou images à caractère sexuel.
- Harcèlement, public ou privé.
- Publier des informations privées sur quelqu'un sans son accord.
- Tout ce qui serait raisonnablement jugé déplacé dans un cadre professionnel.

## Application

Le mainteneur peut modifier, masquer ou supprimer les commentaires, issues, pull requests et autres contributions qui ne respectent pas ce code, et exclure une personne temporairement ou définitivement. Cela vaut dans tous les espaces du projet et quand quelqu'un représente le projet en public.

Pour signaler un problème, contactez le mainteneur par le profil GitHub [morfredus](https://github.com/morfredus), ou utilisez le signalement privé décrit dans [SECURITY_fr.md](SECURITY_fr.md) si c'est sensible. Les signalements sont traités de façon confidentielle et équitable.
